# 四足机器狗质量、惯量与摩擦辨识方案

## 1. 目标

本文档说明如何为四足机器狗辨识以下参数，并将结果用于强化学习 Sim2Real：

- 整机和各部件质量；
- 机身和连杆质心；
- 机身转动惯量；
- 关节等效惯量；
- 关节库仑摩擦、黏性摩擦和静摩擦；
- 足端与地面的静摩擦和动摩擦。

质量、惯量和摩擦不能仅靠一组运动数据同时可靠辨识。推荐原则：

```text
能直接测量的参数优先直接测量
→ 再做单关节受控实验
→ 最后通过仿真回放联合验证
```

推荐流程：

```text
整机和部件称重
→ 测量水平质心
→ 获取CAD质量、质心和惯量
→ 悬空单关节摩擦实验
→ 悬空单关节动态惯量实验
→ 机身摆实验
→ 足端材料地面摩擦实验
→ 仿真复现实验
→ 生成强化学习域随机化范围
```

---

## 2. 参数分类和推荐方法

| 类型 | 参数 | 推荐方法 | 可信度 |
|---|---|---|---|
| 总质量 | 完整机器狗质量 | 电子秤直接称重 | 高 |
| 部件质量 | 机身、电池、髋、大腿、小腿、足端 | 拆卸称重或 CAD/BOM | 高/中 |
| 水平质心 | 机身质心 x、y | 四秤法或两秤法 | 高 |
| 质心高度 | 机身质心 z | CAD、悬挂法或倾斜称重 | 中 |
| 机身惯量 | Ixx、Iyy、Izz | CAD、双线摆或三线摆 | 中/高 |
| 关节等效惯量 | 电机、减速器和连杆折算惯量 | 悬空动态轨迹拟合 | 中 |
| 库仑摩擦 | 与方向有关的近似恒定摩擦力矩 | 恒速正反运动 | 中 |
| 黏性摩擦 | 与关节速度近似成正比的摩擦 | 多速度恒速运动 | 中 |
| 静摩擦 | 关节开始运动前的最大阻力 | 缓慢增加位置偏差/力矩 | 中 |
| 地面静摩擦 | 足端开始滑动前的摩擦 | 滑块拉力或倾斜板 | 高 |
| 地面动摩擦 | 足端稳定滑动时的摩擦 | 滑块恒速牵引 | 中/高 |

强化学习不一定需要每个参数都具有非常准确的物理意义，更重要的是：

1. 参数中心值接近实机；
2. 不确定范围有实验依据；
3. 使用相同输入时，仿真与实机关键响应接近；
4. 域随机化范围不过窄，也不过度扩大。

---

## 3. 质量辨识

## 3.1 整机总质量

总质量不要通过动态轨迹拟合，直接使用电子秤测量。

### 测量状态

必须按照实际强化学习部署状态称重，包括：

- 电池；
- 上位机；
- 相机、雷达和 IMU；
- 外壳；
- 线束；
- 比赛机构；
- 其他长期安装的设备。

### 操作步骤

1. 将电子秤放在水平地面并清零；
2. 将完整机器狗放到秤上；
3. 等待读数稳定；
4. 测量 3～5 次；
5. 记录平均值、最大值和最小值。

记录示例：

```yaml
total_mass:
  measurements_kg: [15.41, 15.43, 15.42, 15.41, 15.42]
  mean_kg: 15.418
  deployment_state: "安装电池、上位机、相机和外壳"
```

### 强化学习使用

仿真所有刚体质量之和应满足：

\[
m_{sim,total}=\sum_i m_i\approx m_{real,total}
\]

如果实测总质量可信，可以先设置：

```text
基础质量随机范围：实测中心值 ±3%～5%
```

真实任务中存在可变负载时，应单独随机附加负载，而不是随意扩大所有连杆质量。

---

## 3.2 各部件质量

如果允许拆卸，分别称量：

```text
机身主体
电池
计算机和传感器
髋部组件 × 4
大腿组件 × 4
小腿组件 × 4
足端 × 4
```

同类部件也建议逐个称量，用于发现装配、线束或零件差异。

如果无法拆卸，使用 CAD/BOM 数据。设 CAD 总质量为：

\[
m_{CAD}=\sum_i m_{i,CAD}
\]

实测总质量为：

\[
m_{real}
\]

整体修正比例为：

\[
s_m=\frac{m_{real}}{m_{CAD}}
\]

可以暂时按比例修正：

\[
m_{i,corrected}=s_m m_{i,CAD}
\]

但更合理的做法是：

- CAD 未建模的控制器、线束和外壳质量主要增加到机身；
- 不要平均增加到所有腿部连杆；
- 电池等大质量设备应根据真实安装位置单独建模。

---

## 4. 质心辨识

## 4.1 四秤法测量水平质心

将四个足端分别放在四个电子秤或垂直力传感器上，记录：

\[
F_{FL},F_{FR},F_{RL},F_{RR}
\]

首先检查：

\[
F_{FL}+F_{FR}+F_{RL}+F_{RR}\approx mg
\]

设前后支撑点距离为 \(L\)，左右支撑点距离为 \(W\)。从后足方向向前计算：

\[
x_{com}=L\frac{F_{FL}+F_{FR}}{F_{FL}+F_{FR}+F_{RL}+F_{RR}}
\]

从右侧向左计算：

\[
y_{com}=W\frac{F_{FL}+F_{RL}}{F_{FL}+F_{FR}+F_{RL}+F_{RR}}
\]

正负方向必须根据机器狗的坐标系定义调整。

### 测量时记录

```text
四个足端在机身坐标系中的位置
机身横滚、俯仰和偏航
关节角
机身高度
电池和设备安装状态
是否开启主动控制
四个秤的读数
```

主动 PD 控制会改变支撑力分布。推荐使用固定机械姿态，或至少保持完全相同的关节目标和增益重复测量。

## 4.2 两秤法

如果只有两个秤：

1. 前两脚放一个秤，后两脚放一个秤，测前后方向质心；
2. 将机器狗旋转 90°，测左右方向质心。

## 4.3 质心高度

四秤法只能直接确定水平质心位置，不能直接确定质心高度。质心高度可通过：

- CAD；
- 悬挂法；
- 倾斜平台称重；
- 摆实验。

初期建议以 CAD 为中心，在强化学习中对 z 方向质心做小范围随机化。

---

## 5. 惯量辨识

需要区分：

1. 机身转动惯量；
2. 各连杆 CAD 惯量；
3. 关节等效惯量。

对于强化学习，建议优先保证：

```text
总质量正确
> 质心正确
> 机身主要惯量合理
> 关节等效动态合理
> 每根连杆完整惯量矩阵精确
```

---

## 5.1 CAD 惯量

从 CAD 导出每个刚体的：

```text
mass
center_of_mass_x/y/z
Ixx、Iyy、Izz
Ixy、Ixz、Iyz
```

注意：

- CAD 惯量参考点必须与 URDF link 坐标系一致；
- 如果 CAD 输出的是质心坐标系惯量，URDF 中惯性原点也应位于相应质心；
- 单位通常需要确认是 kg·m²，而不是 kg·mm²；
- 导出时必须包含真实材料和已安装部件；
- 左右对称部件仍要检查坐标轴方向和惯量积符号。

如果 CAD 和实测总质量不一致，应先修正质量和漏建模部件，再使用惯量数据。

---

## 5.2 机身转动惯量

机身主要惯量为：

\[
I_{xx},I_{yy},I_{zz}
\]

推荐使用双线摆或三线摆实验进行校验。

### 基本步骤

1. 可靠悬挂机身或完整机器狗；
2. 选择待测旋转轴；
3. 施加小角度初始偏转；
4. 自由释放；
5. 记录 10～20 个摆动周期；
6. 测量悬线长度、悬点间距、质量和几何尺寸；
7. 使用与实际悬挂结构对应的摆实验公式计算惯量。

不同摆结构的公式不同，不能在不知道悬挂几何参数时套用统一公式。

单周期人工计时误差较大，平均周期应计算为：

\[
T=\frac{t_N-t_0}{N}
\]

如果不方便做摆实验：

1. 使用 CAD 惯量作为中心值；
2. 确保总质量和质心正确；
3. 对机身惯量做约 ±10%～20% 随机化；
4. 用站立推扰和转向实验验证范围。

---

## 5.3 关节等效惯量

机器狗悬空，其他关节固定，只让一个关节运动。

单关节近似动力学模型：

\[
\tau
=J_{eq}\ddot q
+b\dot q
+\tau_c\operatorname{sign}(\dot q)
+\tau_g(q)
+\tau_0
\]

其中：

- \(J_{eq}\)：关节等效惯量；
- \(b\)：黏性摩擦系数；
- \(\tau_c\)：库仑摩擦；
- \(\tau_g(q)\)：重力力矩；
- \(\tau_0\)：力矩零偏。

重力项可近似展开为：

\[
\tau_g(q)=a\sin q+c\cos q
\]

得到线性参数模型：

\[
\tau
=J_{eq}\ddot q
+b\dot q
+\tau_c\operatorname{sign}(\dot q)
+a\sin q
+c\cos q
+\tau_0
\]

回归矩阵：

\[
Y=\begin{bmatrix}
\ddot q & \dot q & \operatorname{sign}(\dot q) & \sin q & \cos q & 1
\end{bmatrix}
\]

参数向量：

\[
\beta=\begin{bmatrix}
J_{eq} & b & \tau_c & a & c & \tau_0
\end{bmatrix}^T
\]

求解：

\[
\hat\beta=\arg\min_\beta\|Y\beta-\tau\|^2
\]

应增加约束：

```text
J_eq >= 0
b >= 0
tau_c >= 0
```

### 推荐激励

使用当前参数辨识程序的多组 `sine`：

```text
振幅：0.03、0.05、0.08 rad
频率：0.2、0.5、1.0、1.5、2.0 Hz
每组：10～20秒
每组重复：3次
```

同一关节至少选择 3 个中心角，避免重力项和摩擦、零偏耦合。

### 加速度计算

需要计算：

\[
\ddot q=\frac{d\dot q}{dt}
\]

不要直接对原始速度进行简单差分。推荐：

1. 对位置或速度进行低通滤波；
2. 使用 Savitzky–Golay 滤波；
3. 对平滑后的位置拟合曲线，再计算一阶和二阶导数。

直接差分会放大速度噪声，导致惯量估计严重偏差。

## 6. 力矩数据要求

惯量和摩擦辨识是否可信，主要取决于力矩数据。

当前日志中的 `tau_meas_nm` 必须确认其实际含义：

```text
电机电流换算力矩？
电机轴力矩？
减速器输出端力矩？
STM32计算的PD目标力矩？
滤波后的估计值？
```

如果只有位置 PD，可以计算：

\[
\tau_{pd}=K_p(q_{cmd}-q)-K_d\dot q
\]

但必须确认：

- STM32 实际公式与此一致；
- Kp、Kd 单位一致；
- 是否存在额外增益缩放；
- 是否经过力矩限幅；
- 是否有电流环或电机内部位置环；
- 速度是否经过滤波；
- 目标角是否在 STM32 中再次插值或滤波。

如果能读取电机电流 \(I\)，关节输出力矩可近似：

\[
\tau_{joint}=\eta N K_t I
\]

其中：

- \(K_t\)：电机力矩常数；
- \(N\)：减速比；
- \(\eta\)：传动效率。

建议 STM32 增加记录：

```text
motor_current_raw
tau_pd_raw
tau_after_limit
position_command_received
position_command_applied
battery_voltage
motor_temperature
command_sequence
feedback_sequence
```

没有可靠力矩数据时，只能辨识位置命令到运动的等效动态，不能宣称得到精确物理惯量。

---

## 7. 关节摩擦辨识

关节摩擦初期可使用：

\[
\tau_f=b\dot q+\tau_c\operatorname{sign}(\dot q)
\]

其中：

- \(b\)：黏性摩擦；
- \(\tau_c\)：库仑摩擦。

复杂情况下可使用 Stribeck 模型，但不建议作为第一版。

---

## 7.1 恒速正反运动

正弦速度一直变化，不是辨识摩擦的最佳输入。建议给程序增加 `triangle` 三角位置轨迹：

```yaml
experiment:
  type: "triangle"
  duration_seconds: 30.0

  triangle:
    lower_offset_rad: -0.10
    upper_offset_rad: 0.10
    velocity_rad_s: 0.20
    endpoint_hold_seconds: 1.0
```

轨迹过程：

```text
center - 0.10 rad
→ 以恒定速度到 center + 0.10 rad
→ 保持
→ 以恒定速度返回
→ 保持
→ 重复
```

推荐速度：

```text
0.05 rad/s
0.10 rad/s
0.20 rad/s
0.40 rad/s
0.80 rad/s
```

第一轮只使用：

```text
0.05、0.10、0.20 rad/s
```

每个速度正反往返至少 5 次。

三角轨迹中间段近似：

\[
\dot q\approx v,\qquad\ddot q\approx0
\]

因此：

\[
\tau\approx\tau_g(q)+b\dot q+\tau_c\operatorname{sign}(\dot q)
\]

### 正反方向消除重力

在相近角度范围使用相同绝对速度：

\[
\tau_+=\tau_g+\tau_c+bv
\]

\[
\tau_-=\tau_g-\tau_c-bv
\]

重力项：

\[
\tau_g=\frac{\tau_++\tau_-}{2}
\]

摩擦项：

\[
\tau_f(v)=\frac{\tau_+-\tau_-}{2}=\tau_c+bv
\]

对多组速度进行直线拟合：

```text
截距 = 库仑摩擦 tau_c
斜率 = 黏性摩擦 b
```

正反方向数据必须来自相近角度，否则重力力矩不同，不能直接相减。

### 分析时排除

- 换向点；
- 加速和减速阶段；
- 端点保持阶段；
- 速度尚未稳定的数据；
- 力矩饱和数据；
- 反馈丢失附近数据。

---

## 7.2 静摩擦辨识

静摩擦可通过缓慢增加位置偏差，直到关节开始运动来估计。

建议轨迹配置：

```yaml
experiment:
  type: "breakaway"

  breakaway:
    command_increment_rad: 0.0005
    increment_interval_seconds: 0.05
    max_offset_rad: 0.05
    motion_velocity_threshold_rad_s: 0.02
    motion_confirm_seconds: 0.05
```

流程：

```text
保持中心角
→ 每隔固定时间增加很小的目标角偏移
→ PD位置误差逐渐增大
→ 检测关节开始运动
→ 记录启动瞬间位置误差和力矩
→ 停止增加并安全返回
```

关节启动前速度接近零时：

\[
\tau_s\approx K_p(q_{cmd}-q)
\]

更推荐直接使用 STM32 返回的实际力矩或电机电流。

正负方向必须分别测试：

```text
command_increment_rad > 0
command_increment_rad < 0
```

静摩擦实验可能在克服摩擦后突然运动，必须：

- 使用很小的目标增量；
- 使用较低 Kp；
- 限制最大偏移；
- 限制最大力矩；
- 检测到运动后立即停止增加；
- 机器狗可靠悬空；
- 急停可用。

---

## 8. 地面摩擦辨识

地面摩擦与关节摩擦不同，主要包括：

- 静摩擦系数 \(\mu_s\)；
- 动摩擦系数 \(\mu_k\)。

---

## 8.1 足端材料滑块法

这是最推荐的方法，受机器人主动控制影响最小。

### 设备

```text
与足端相同材料和接触形状的滑块
已知质量砝码
水平拉力计
目标地面
固定相机或数据记录设备
```

### 操作

1. 测量滑块和砝码总质量 \(m\)；
2. 将拉力计保持水平；
3. 缓慢增加拉力；
4. 记录开始滑动前的最大拉力 \(F_{start}\)；
5. 保持低速稳定滑动；
6. 记录稳定滑动平均力 \(F_{slide}\)；
7. 每种地面重复 5～10 次；
8. 更换载荷重复，检查结果是否稳定。

计算：

\[
\mu_s=\frac{F_{start}}{mg}
\]

\[
\mu_k=\frac{F_{slide}}{mg}
\]

记录：

| 地面 | 质量 | 启动力 | 稳定滑动力 | 静摩擦 | 动摩擦 |
|---|---:|---:|---:|---:|---:|
| 瓷砖 |  |  |  |  |  |
| 水泥 |  |  |  |  |  |
| 橡胶垫 |  |  |  |  |  |
| 木板 |  |  |  |  |  |

同时记录地面是否潮湿、是否有灰尘、足端磨损程度和温度。

---

## 8.2 倾斜板法

缓慢增加平板角度，记录滑块刚开始滑动的角度 \(\theta_s\)：

\[
\mu_s=\tan\theta_s
\]

优点：

- 不需要高精度拉力计；
- 水平拉力方向误差较小；
- 操作简单。

缺点：

- 不容易测量动摩擦；
- 平板倾斜速度会影响结果；
- 足端形变、滚动或翻转会影响结果。

---

## 8.3 整机牵引法

机器狗保持固定姿态，四足接触地面，用拉力计水平缓慢拉机身。

估计：

\[
\mu_s\approx\frac{F_{start}}{mg}
\]

但主动位置控制会改变各足法向力，因此测得的是整机等效摩擦，不是纯材料摩擦。

必须记录：

```text
机器狗质量
关节姿态
Kp/Kd
是否开机
四足是否同时滑动
开始滑动的足端
地面类型
拉力方向
```

---

## 8.4 仿真器等效摩擦

物理实验得到的摩擦系数不一定能直接填入 MuJoCo、Gazebo、Isaac Gym 或 Isaac Lab。不同仿真器的接触模型和摩擦组合规则不同。

应在仿真中复现相同滑块实验：

```text
相同滑块质量
相同接触面积和材料
相同法向载荷
相同倾斜角或水平拉力
```

调整仿真摩擦参数，使：

- 开始滑动角；
- 开始滑动力；
- 稳定滑动速度或加速度；
- 停止后的滑动距离

与实测接近。

最终用于强化学习的是仿真器中的等效摩擦范围，不一定与物理测量数值完全相同。

## 9. 建议扩展当前 C++ 程序

当前 `atdog3_joint_identification.cpp` 已支持：

```text
hold
smooth_step
sine
```

为了辨识惯量和摩擦，建议后续增加：

### 9.1 triangle

用途：多速度恒速正反运动，主要辨识库仑摩擦和黏性摩擦。

建议参数：

```yaml
triangle:
  lower_offset_rad: -0.10
  upper_offset_rad: 0.10
  velocity_rad_s: 0.10
  endpoint_hold_seconds: 1.0
  cycles: 5
```

### 9.2 chirp

用途：连续扫频，主要分析执行器频率响应、共振和等效动态。

```yaml
chirp:
  amplitude_rad: 0.03
  start_frequency_hz: 0.10
  end_frequency_hz: 2.00
```

线性扫频相位应为：

\[
\phi(t)=2\pi\left(f_0t+\frac{f_1-f_0}{2T}t^2\right)
\]

轨迹：

\[
q_{cmd}(t)=q_c+A\sin(\phi(t))
\]

### 9.3 breakaway

用途：缓慢增加位置偏差，测量正负方向静摩擦和死区。

```yaml
breakaway:
  command_increment_rad: 0.0005
  increment_interval_seconds: 0.05
  max_offset_rad: 0.05
  motion_velocity_threshold_rad_s: 0.02
  motion_confirm_seconds: 0.05
```

## 10. 数据处理流程

### 10.1 数据筛选

只使用：

```text
phase == RUN_EXPERIMENT
enabled == 1
feedback_ok == 1
set_target_ok == 1
```

排除：

- 启动和返回中心角阶段；
- 反馈重复或丢失数据；
- 力矩饱和数据；
- 速度和力矩异常点；
- 三角轨迹换向点；
- 静摩擦实验启动后的突然运动阶段。

### 10.2 时间轴

优先使用 STM32 时间戳，但需要：

- 确认单位；
- 处理 32 位回绕；
- 检查重复时间戳；
- 检查采样间隔；
- 不要直接把 PC 和 STM32 的绝对时间相减。

### 10.3 滤波与求导

建议：

1. 对位置和速度检查异常值；
2. 使用低通或 Savitzky–Golay 滤波；
3. 从平滑后的速度计算加速度；
4. 保留滤波前后数据；
5. 对滤波引入的相位延迟进行检查。

### 10.4 参数拟合

建议分阶段拟合：

```text
先估计并补偿延迟
→ 恒速段拟合摩擦
→ 固定摩擦后拟合惯量和重力项
→ 使用独立轨迹验证
```

不要一次同时自由优化质量、惯量、摩擦、电机强度、延迟和 Kp/Kd。

## 11. 参数耦合和解决方法

### 11.1 质量与电机强度

实机加速度小可能来自：

```text
质量大
惯量大
电机输出弱
力矩限幅小
控制延迟大
```

解决：

- 质量直接称重；
- 电流和力矩比例用已知负载校准；
- 延迟先单独测量；
- 最后拟合惯量。

### 11.2 惯量与黏性摩擦

两者都会增加动态运动所需力矩。

解决：

- 恒速段主要拟合摩擦；
- 高加速度段在固定摩擦后拟合惯量。

### 11.3 库仑摩擦与重力

单方向运动时，两者可能都表现为近似常量力矩。

解决：

- 同一角度范围进行正反运动；
- 对正反力矩取半和、半差；
- 在多个中心角重复实验。

### 11.4 延迟与惯量

未建模延迟会产生相位滞后，优化器可能错误地增加惯量来补偿。

解决：

1. 先通过 `q_cmd` 和 `q_meas` 对齐估计延迟；
2. 对齐时间后再拟合惯量；
3. 使用多个频率验证相位。

## 12. 已知负载验证

在允许且安全时，可在足端增加已知质量：

```text
0 kg
0.2 kg
0.4 kg
```

点质量 \(m_L\) 距关节轴距离为 \(r\)，增加惯量近似：

\[
\Delta J=m_Lr^2
\]

新增负载带来的力矩变化近似：

\[
\Delta\tau=m_Lr^2\ddot q+m_Lgr\sin(q+\phi)
\]

用途：

- 校验力矩换算比例；
- 校验惯量拟合；
- 校验重力模型；
- 判断模型是否能推广到不同负载。

负载必须可靠固定，并重新检查软限位、最大速度和力矩保护。

---

## 13. 仿真回放验证

辨识参数不能只看回归误差，必须在仿真中执行相同输入。

保持一致：

```text
初始关节角
q_cmd时间序列
控制频率
Kp/Kd
速度和力矩限制
动作延迟
实验时长
重力方向
```

比较：

```text
q_sim 与 q_real
dq_sim 与 dq_real
tau_sim 与 tau_real
幅值比
相位差
上升时间
超调量
稳态误差
```

训练数据和验证数据应分开，例如：

```text
拟合数据：0.2、0.5、1.0 Hz
验证数据：0.8、1.5 Hz
```

只在拟合轨迹上误差小，不能证明参数可以用于强化学习。

## 14. 强化学习中的使用方式

### 14.1 质量

只在 episode reset 时采样：

```python
base_mass = identified_mass + uniform(-mass_delta, mass_delta)
```

建议：

```text
总质量测量可信：±3%～5%
可变负载：按真实装载范围单独随机
腿部质量：以称重/CAD为中心小范围随机
```

### 14.2 质心

```python
com_x = uniform(x_min, x_max)
com_y = uniform(y_min, y_max)
com_z = uniform(z_min, z_max)
```

x/y 有称重数据时范围应较小，z 不确定时可适当扩大。

### 14.3 惯量

最简单安全的方式是整体缩放辨识或 CAD 惯量：

```python
inertia_scale = uniform(0.85, 1.15)
inertia = identified_inertia * inertia_scale
```

不要独立生成不满足物理约束的惯量。刚体主惯量应满足：

\[
I_{xx}+I_{yy}\ge I_{zz}
\]

以及其他两个循环不等式。

### 14.4 关节摩擦

```python
viscous_friction = b_identified * uniform(0.8, 1.2)
coulomb_friction = tau_c_identified * uniform(0.7, 1.3)
```

如果仿真器只有一个关节摩擦参数，应通过相同轨迹回放寻找等效值。

### 14.5 地面摩擦

```python
ground_friction = uniform(mu_low, mu_high)
```

范围应覆盖机器人真实使用的地面，但不要无限扩大。可以先在常见地面范围训练，再逐渐扩大到低摩擦和高摩擦。

## 16. 最重要的结论

```text
质量优先称出来；
质心优先用称重法；
机身惯量优先用CAD和摆实验；
关节摩擦使用多速度恒速正反运动；
关节等效惯量使用高质量力矩数据和动态轨迹；
地面摩擦使用足端材料独立实验；
所有结果最后必须通过仿真轨迹回放验证。
```

不建议直接编写一个黑盒优化器，同时自由优化质量、惯量、摩擦、电机强度、延迟和增益。即使轨迹拟合误差很小，也可能只是参数之间互相补偿，无法可靠用于强化学习域随机化。
